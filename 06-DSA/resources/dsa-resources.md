## Suggested path
1. **Foundations (2–3 weeks):** Grokking Algorithms or Abdul Bari + implement each structure yourself once.
2. **The grind (8–12 weeks):** ONE sheet — NeetCode 150 or Striver A2Z. Pattern-first: arrays → two pointers → sliding window → hashmaps → trees → graphs → DP.
3. **Simulate:** weekly timed mocks (2 mediums in 60 min, talking out loud).
4. **Maintenance:** re-solve failures after 3 days and again after 3 weeks (spaced repetition).
