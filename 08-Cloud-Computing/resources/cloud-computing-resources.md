## 🏅 Certification ladder (optional but resume-strong)
1. **AWS Cloud Practitioner / AZ-900 / GCP Digital Leader** (fundamentals) → 2. **AWS Solutions Architect Associate / AZ-104** (associate) → 3. Specialty: Security, DevOps Pro, Data.

## 🗺️ Suggested path
1. **Concepts first:** this repo's notes + one fundamentals course (AWS CP or AZ-900 level).
2. **Hands-on weekly:** free-tier projects — host a static site on S3+CDN, deploy a 3-tier app, build a serverless API.
3. **Read one whitepaper:** Well-Architected Framework — it teaches you to *design*, not just name services.
4. **Interview polish:** this repo's 25 Q&A + practice narrating the shared responsibility model and a 3-tier architecture from memory.
