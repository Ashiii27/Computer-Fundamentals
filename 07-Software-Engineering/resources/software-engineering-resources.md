# Software Engineering — Curated Learning Resources

> Books → References & Guides → YouTube → Practice. Starred items = best value.

## Books
| Resource | Why | Link |
|---|---|---|
| **Software Engineering** — Ian Sommerville | THE standard textbook; process, requirements, architecture, testing | Print / Pearson |
| **Software Engineering: A Practitioner's Approach** — Roger Pressman | The other classic; exam-oriented coverage | Print / McGraw-Hill |
| **Software Engineering at Google** — Winters, Manshreck, Wright | **Free to read online**; modern engineering culture, testing, code review at scale | https://abseil.io/resources/swe-book |
| **The Mythical Man-Month** — Fred Brooks | Timeless essays on software projects (Brooks' Law) | Print / Addison-Wesley |
| **Clean Code** — Robert C. Martin | Craft-level quality practices | Print / Prentice Hall |

## Practice
| Exercise | Skills drilled |
|---|---|
| **Write an SRS** for a familiar app (library/canteen system): functional + NFRs | Requirements engineering |
| **Draw UML**: use case + class + sequence for the same app | Design communication |
| **Write test cases** for a login feature with EP + BVA, and classify smoke/sanity/regression | Testing techniques |
| **Run a mini-sprint** on a personal project: backlog → sprint board → retro notes | Scrum hands-on |
| **CMMI/SDLC quizzes** on GeeksforGeeks | Exam recall |

## Suggested path
1. **Theory base:** Sommerville (or Pressman) selected chapters + this repo's notes; GfG MCQs for recall.
2. **Agile hands-on:** Scrum Guide + Atlassian Agile Coach; run your own kanban board for a month.
3. **Testing depth:** write real test suites for a hobby project; learn the confusing-pairs table cold.
4. **Modern context:** *Software Engineering at Google* (free) — bridges SE theory to industry practice.
