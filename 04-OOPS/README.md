## 🎯 Suggested revision order
1. Classes/objects + the 4 pillars (with real-life analogies)
2. Abstract class vs interface; overloading vs overriding
3. Constructors, copy semantics, static members
4. Inheritance types + diamond problem
5. SOLID principles (one example each)
6. Design patterns: Singleton, Factory, Observer, Strategy minimum

## ⭐ Must-know for interviews
- Encapsulation vs abstraction (the classic confusion)
- Method overloading vs overriding (rules + static method trap)
- Abstract class vs interface + when to use which
- Diamond problem & how C++/Java solve it
- SOLID — be able to explain each in one line with an example
- Singleton (thread-safe), Factory, Observer, Strategy patterns
- Aggregation vs composition vs association
