# OOPS — Curated Learning Resources

> Books → Websites → YouTube → Practice. Starred items = best value.

## Books
| Resource | Why | Link |
|---|---|---|
| **Head First Object-Oriented Analysis & Design** | OOP thinking + design, approachable and example-driven | Print / O'Reilly |
| **Clean Code** — Robert C. Martin | How good OOP looks in practice (naming, functions, classes) | Print / Prentice Hall |
| **Head First Design Patterns** | The friendliest real intro to the GoF patterns | Print / O'Reilly |
| **Design Patterns** — Gamma, Helm, Johnson, Vlissides (GoF) | The original reference (dense — read after Head First) | Print / Addison-Wesley |
| **Effective Java** — Joshua Bloch | Java-specific OOP mastery (if Java is your language) | Print / Addison-Wesley |

## Practice (the real differentiator)
| Exercise | Skills drilled |
|---|---|
| **LLD rounds**: design a Parking Lot, Elevator System, Splitwise, BookMyShow, LRU Cache | Classes, interfaces, SOLID, patterns — say them out loud while designing |
| **Refactor a messy class**: find an if/else-per-type and replace it with polymorphism/strategy | OCP, LSP hands-on |
| **Implement patterns yourself**: Singleton (3 thread-safe ways), Observer (event bus), Decorator (coffee shop) | Pattern fluency without rote memorization |
| **Draw UML** for a library/order system on paper (classes, arrows, diamonds) | Communication skills for whiteboard rounds |
| **LeetCode design problems** (146 LRU Cache, 155 Min Stack, 346 Moving Average) | OOP + DS together, with a judge to verify |

## Suggested path
1. **Concepts:** this repo's notes + Refactoring.Guru + one OOP course video series.
2. **Patterns:** Head First Design Patterns (or Christopher Okhravi's series) — implement 5 by hand.
3. **SOLID:** DigitalOcean series + hunt violations in your own old code.
4. **Interview mode:** this repo's 30 Q&A + 2–3 full LLD designs practiced end-to-end.
