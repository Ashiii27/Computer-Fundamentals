2. Encryption vs hashing vs encoding; symmetric vs asymmetric
3. TLS/HTTPS handshake + certificates
4. Web attacks: XSS, SQLi, CSRF + prevention

## ⭐ Must-know for interviews
- CIA triad; AAA (authentication, authorization, accounting)

- How HTTPS works end-to-end (TLS handshake)
- XSS vs CSRF (difference + fixes); SQL injection prevention
- IDS vs IPS; firewall types; VPN; zero trust
- OWASP Top 10 current list; incident response steps
