## Suggested path
1. **Weeks 1–4:** TryHackMe "Pre-Security" + Professor Messer Security+ videos alongside this repo's notes.
2. **Weeks 5–10:** PortSwigger Web Security Academy — finish the SQLi, XSS, access-control halls.
3. **Hands-on forever:** OverTheWire Bandit → picoCTF → easy HackTheBox machines; document write-ups.
4. **Career-direction:** blue team (SOC: learn a SIEM, NIST IR) vs red team (OSCP path) vs appsec (Burp + code review).
5. **Ethics reminder:** written authorization before testing anything you don't own.
