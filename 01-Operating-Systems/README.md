## ⭐ Must-know for interviews
- Process vs Thread vs Program
- Deadlock — 4 necessary conditions + prevention/avoidance
- Mutex vs Semaphore
- Paging vs Segmentation, Virtual memory, Thrashing
- Page replacement algorithms (FIFO / LRU / Optimal) + Belady's anomaly
- FCFS / SJF / Round Robin scheduling (practice 1–2 numericals)
