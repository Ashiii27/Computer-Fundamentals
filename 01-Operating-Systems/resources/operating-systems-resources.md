# Operating Systems — Curated Learning Resources

> Books → Courses → YouTube → Docs/Websites → Practice. Starred items are the highest value-to-effort picks.

## Books
| Resource | Why | Link |
|---|---|---|
| **Operating Systems: Three Easy Pieces (OSTEP)** — Arpaci-Dusseau | The best modern OS book — free to read online, conversational, covers everything interviewers ask | https://pages.cs.wisc.edu/~remzi/OSTEP/ |
| **Operating System Concepts (10th ed.)** — Silberschatz, Galvin, Gagne | The classic "dinosaur book"; standard for GATE/placements | https://www.db-book.com (slides + practice) |
| **Modern Operating Systems** — Tanenbaum | Deeper theoretical treatment; great for microkernels, distributed OS | Print / Pearson |
| **Linux Kernel Development** — Robert Love | How a real kernel (Linux) implements scheduling, memory, interrupts — read after the basics | Print / InformIT |

## Suggested path
1. **First pass (concepts):** Gate Smashers / Jenny's Lectures alongside OSTEP chapters.
2. **Second pass (depth):** Silberschatz for sync, deadlock, memory chapters + solve numericals.
3. **Interview polish:** GfG Last Minute Notes + the Q&A file in this repo + practice 2–3 scheduling/page-replacement numericals on paper.
